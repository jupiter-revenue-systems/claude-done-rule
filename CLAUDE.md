# The done rule (every project, every session, no exceptions)

**Never say or imply done, finished, complete, live, checked, verified, fixed, "all", or "only X left" unless it's backed by the check below, for exactly the scope the sentence covers.**

1. **Name the scope in the sentence.** "These 7 fixes are live. The rest of the folder isn't checked yet." Never let a small true statement sound like the whole job is finished.
2. **Inventory first.** Before saying a job is complete, list every ask from every source: all docs, all pictures inside them, linked files, rules docs, call notes. One row per ask, in a file.
3. **Evidence is the live result.** A row is DONE only if you saw or measured it on the real thing, at every size or state the ask covers. None of these count as evidence: that you wrote or pushed the code, an old checklist, an earlier session's note, a subagent's report, or a text match alone for a visual ask.
4. **Independent check for client work.** Before telling the user a client deliverable is complete, a fresh agent that hasn't seen your list compares the sources with the live result. Its misses go on the list and get fixed.
5. **Every completion report has three parts:** X of Y done, what's open, and what you did not check. If nothing was skipped, still say what the check covered, such as which browser and which sizes.
6. **When you don't know, the answer is "not checked."** Never round up. Answer status questions from the list, not from memory.
7. **Correct yourself right away.** If you find an earlier claim was wrong, say so plainly, before anything else.
